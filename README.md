# Eron PVP Resource Packs

PvP resource packs for **Minecraft 1.21.11** (Java Edition). Every edition has the same features and
differs only in colour. Download a zip from the [`packs`](packs) folder, put it into your
`resourcepacks` folder and move it to the top of the pack list.

| Edition | Colours | File |
|---|---|---|
| Lava | yellow, orange, dark gold | [`EronPVPLavaEdition.zip`](packs/EronPVPLavaEdition.zip) |
| Snow | white and gray | [`EronPVPSnowEdition.zip`](packs/EronPVPSnowEdition.zip) |
| Onix | red, black, purple | [`EronXDy_onix.zip`](packs/EronXDy_onix.zip) |
| Astral | blue, green, purple | [`EronPVPAstralEdition.zip`](packs/EronPVPAstralEdition.zip) |
| Blackout | black and dark gray | [`EronPVPBlackoutEdition.zip`](packs/EronPVPBlackoutEdition.zip) |
| Sakura | pastel pink, mint, white | [`EronPVPSakuraEdition.zip`](packs/EronPVPSakuraEdition.zip) |

## Features

- Recoloured armour and tool tiers (iron, diamond, netherite), totem, mace, bow, crossbow, arrows,
  fishing rod, shield, elytra, ender pearl, wind charge, potions and bottle o' enchanting
- Short swords and smaller items in hand; slightly lower shield
- Particle filter: only crits, sweeps, firework explosions and the totem pop are shown, and the
  totem particles are recoloured; block particles take the edition colour
- No red flash when an entity is hit
- Smaller totem pop animation, low one-pixel fire
- Dark gray inventory and container GUI with readable titles, darker hotbar
- Custom hearts, apple-shaped hunger icons, absorption hearts in a separate colour
- Mace changes colour with Breach or Density
- UHC: framed ores, low grass and ferns, clearer water, no pumpkin blur, vignette or underwater
  overlay

The packs use core shaders, so they need Minecraft 1.21.11 and do not work with Iris shader packs
enabled. Damage tilt, FOV effects and view bobbing cannot be changed by a resource pack; turn them off
in the game options.
